# NumPy Analyzer 🐍

A Python-based data analysis project built using NumPy. It allows users to create and manipulate arrays, perform mathematical operations, and calculate statistical values through a menu-driven interface.

## 🚀 Features
- Create 1D, 2D, and 3D NumPy arrays
- Perform mathematical operations
- Combine and split arrays
- Search, sort, and filter values
- Perform array slicing
- Calculate sum, mean, median, standard deviation, and variance
- Calculate correlation between arrays

## 🛠️ Technologies Used
- Python
- NumPy
- Object-Oriented Programming (OOP)

## ⚙️ Installation
Install NumPy using the following command:

pip install numpy

## ▶️ How to Run
Run the Python file using:

python main.py

## 🎯 Purpose
This project demonstrates practical knowledge of Python, NumPy, OOP concepts, and basic data analysis operations.
